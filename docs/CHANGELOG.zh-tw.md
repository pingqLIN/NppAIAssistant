# 專案更新紀錄

## 尚未發行

### 更安全的 AI 連線設定

- 設定視窗新增請求逾時欄位，預設為 30 秒，可輸入 1 到 300 的整數。模型探索與推論開始時，
  都會保留當下的逾時設定，不會受到之後設定變更的影響。
- 新增選用的 `Local OpenAI-compatible` 供應商，但只允許連線到字面上的 loopback
  OpenAI 相容 `/v1` 端點。本機請求會略過 Proxy、拒絕重新導向，並拒絕遠端主機。
- 已保存的模型只有在服務仍回傳相同模型 ID 時才會恢復選取。模型不存在時，必須由使用者
  明確選擇另一個模型；外掛不會自行改用其他模型。

### 編輯器操作

- 編輯器中的 AI 選單現在必須在選取非空文字後，以滑鼠按住 Ctrl 再按右鍵才會顯示。一般右鍵與
  鍵盤內容選單仍交由 Notepad++ 原生處理。

### 文件與驗證

- README 與使用說明已改以可驗證的設定方式、隱私界線與實際發佈狀態為主。
- 安全性回歸檢查新增逾時設定、loopback 傳輸限制、明確模型選取與右鍵啟用條件的驗證。
