# 將 AI 回覆寫入編輯區

聊天送出前，在預覽／送出控制項上方選擇「輸出位置」：

- **對話面板**（預設）：回覆保留在對話中。
- **插入編輯區**：插入送出時的游標位置，保留原本選取的文字。
- **取代選取文字**：取代單一、非矩形選取範圍；沒有選取文字時會阻止送出。
- **開啟新文件**：回覆成功後建立未儲存文件並寫入。

成功回覆都會保留在對話中。在紀錄下方選擇回覆，再按「插入編輯區」，即可插入目前編輯器的游標位置，保留選取文字。寫入內容與回覆相同，包含模型輸出的 Markdown 程式碼圍欄。

輸出位置會保留到此次程序結束，每次送出前皆可更改。請求進行中更改位置，只影響下一次請求。「送出前預覽」仍可獨立切換。

自動插入／取代會在提示詞預覽前記錄文件與位置。若文件內容、編碼或文件身分已變動，就停止寫入，回覆仍保留在面板。唯讀文件與無法完整表示回覆的編碼也會阻止寫入。既有文件寫入限單一選取、16 MiB 以內；較大的來源可選新文件輸出。每次成功寫入可用一次 Ctrl+Z 復原，且不會自動儲存文件。失敗或驗證不通過的模型回覆不會寫入。
