# 本機供應商與請求逾時

## 已完成的開發計畫

這次變更將四個行為一起落實：

1. 請求逾時欄位以秒為單位，預設 `30`，僅接受 `1` 到 `300` 的整數。
2. 每個模型探索與推論請求會保有自己的逾時快照；儲存新設定不會改變已在執行中的請求。
3. 可選用的 OpenAI 相容供應商僅能連至本機 `/v1` 服務。接受
   `http://127.0.0.1:<port>/v1` 與 `http://[::1]:<port>/v1`；輸入
   `localhost` 時會正規化為 `127.0.0.1`。遠端主機名稱、遠端 IP、轉址、
   Proxy、查詢字串、URL 內帳密與非 `/v1` 路徑都會被拒絕。
4. 模型必須由使用者明確選取後才會使用。若已儲存的模型已不存在，模型欄位會維持未選取，
   請求也會被阻擋；外掛不會改用清單中的第一個模型。

## 操作方式

開啟 **Plugins > NppAIAssistant > Settings**，在 **要求逾時（秒）** 輸入所需秒數後儲存。
不合法的輸入無法儲存。此設定會套用到 OpenAI、Gemini、Claude、本機相容供應商的模型清單、
測試連線與推論。

如要使用本機 OpenAI 相容服務，請輸入上述格式的本機 Base URL，將供應商選為
**Local OpenAI-compatible**，測試連線，最後從回傳清單中明確選擇模型。本機 API Key 為選填，
會儲存在 Windows DPAPI 安全儲存；端點、逾時及所選模型則是一般外掛偏好設定。

## 右鍵功能前處理

AI 右鍵選單只會在 Scintilla 有非空白選取文字，且以滑鼠 Ctrl+右鍵叫出時顯示。一般右鍵、
沒有選取文字的右鍵，以及鍵盤叫出的內容選單，都會回到 Notepad++ 原生處理程序。只有成功建立
AI 快顯選單後，hook 才會攔截該訊息。

## 驗證與剩餘驗收

請執行 `scripts\verify-security-regressions.ps1`，並用 CMake 建置 DLL。發行前仍需在 Notepad++
手動確認原生與 Ctrl 右鍵行為、逾時儲存後重開、端點格式拒絕、已儲存模型消失，以及已設定的
本機服務模型探索。本專案沒有自動化 Notepad++ UI 測試框架，因此上述互動檢查仍是發行門檻。
