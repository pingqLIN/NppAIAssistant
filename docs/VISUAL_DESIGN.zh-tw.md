構圖將角色放在左側，右側留出安靜的空間。深藍背景、暖琥珀毛色與青綠點綴，讓中英文 README 都能共用這張插畫。圖內不嵌入標題，專案名稱保留為可選取、可供輔助工具讀取的 Markdown 文字。
