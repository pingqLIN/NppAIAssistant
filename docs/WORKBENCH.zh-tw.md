# NppAIAssistant 工作台

專案與問題回報：[GitHub](https://github.com/pingqLIN/NppAIAssistant)。工作台選單也提供「使用說明／關於」與「GitHub 專案」。

選單以分隔線整理工作台、對話、選取文字操作及設定／說明。面板右上角「選單」可開啟相同操作。服務／模型與任務／輸出選項位於對話上方；「顯示」切換格式預覽與原文，輸出位置和送出前預覽則保留在輸入區旁。

## 回覆顯示

格式預覽支援 Markdown 標題、粗體、行內程式碼、程式碼區塊、項目清單與引用。JSON 通過解析後才縮排，保留原始數字與字串表示，不會自動修復無效 JSON。這是基本文字呈現：尚不支援表格、巢狀 Markdown、HTML 呈現、圖片或可點擊 Markdown 連結，也不會讀取外部資源。

原文模式保留回覆內容。格式預覽不會改動[寫入編輯器](EDITOR_OUTPUT.zh-tw.md)使用的原始回覆。JSON 格式化限 1 MiB 並沿用解析器的深度／節點上限；有效 JSON 以等寬字型顯示。切換顯示模式不會重新呼叫 AI。

## 請求狀態

準備、連線、傳送、等待、接收及驗證期間顯示旋轉指示。成功、請求錯誤及連線失敗使用不同圖示；結束狀態動畫在八次 350 毫秒更新後停止。遵循 Windows 減少動態效果設定，並保留文字狀態。HTTP 錯誤與傳送／接收連線失敗分開顯示，不會自動重試，也不會在閒置時宣稱連線正常。

## 內建方案提示詞

程式修正要求最小正確修改且不捏造相依套件；重構保留行為與介面；解說区分原始碼證據與假設；測試生成涵蓋正常、邊界與錯誤情境，且不宣稱已執行；文件方案只描述有依據的功能；審查方案優先列出證據、影響與最小修正。只輸出取代內容時排除矛盾的 Markdown／附加風險文字要求。使用者自訂提示詞保持不變，可覆寫內建預設。
