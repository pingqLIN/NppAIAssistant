## 3. Scope

### Included

- Local OpenAI-compatible `/v1` provider safety controls。
- loopback-only endpoint policy。
- per-request timeout，預設 30 秒、1–300 秒。

- Release workflow 與 Plugins Admin update pipeline。

- 新 provider 功能。
- Responses API migration。
- 大型 Settings UI redesign。
- x86 / ARM64 Plugins Admin 正式上架。
- 官方 `nppPluginList` PR 未經核准直接送出。
