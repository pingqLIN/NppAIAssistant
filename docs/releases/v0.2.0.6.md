# NppAIAssistant 0.2.0.6 candidate notes

Windows x64. The DLL basename remains NppAIAssistant.dll.

- Local LM Studio and loopback-compatible generation requests allow 900 seconds
  per WinHTTP phase. Model discovery remains 1.5 seconds.
- The workspace adds basic Markdown/JSON display, raw reply view, and explicit
  output to the panel, cursor, selected text, or a new document.
- Editor writes check document identity, unchanged content, read-only state and
  encoding. Replies remain available when a write is rejected.
- Built-in prompt sections are locked by default and require explicit unlocking.
- Provider failures distinguish transport errors from HTTP status failures.
- Closing the prompt-section dialog preserves workspace fonts.

Use x64 Notepad++. This candidate does not certify a minimum host version or
other architectures. Real-host install/update/remove acceptance is required
before declaring a stable release. Japanese/Spanish cover the main workspace;
advanced settings may fall back to English.

Close Notepad++ before replacing the DLL, and retain the previous DLL for
rollback. Settings and secrets use the current Windows user's AppData and
LocalAppData even with portable Notepad++. Back them up without sharing their
contents before migration testing. Cloud providers may charge for requests.

The 900-second setting is not a guaranteed total request deadline. A successful
short request does not establish long-running generation reliability.
