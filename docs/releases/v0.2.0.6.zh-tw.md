# NppAIAssistant 0.2.0.6 候選版說明

適用 Windows x64，DLL 名稱維持 NppAIAssistant.dll。

- 本機 LM Studio 與 loopback 相容服務的生成請求，各 WinHTTP 階段允許等待
  900 秒；模型探索維持 1.5 秒。
- 工作台提供基本 Markdown／JSON 顯示、原始回覆，以及面板、游標、選取文字、
  新文件等明確輸出位置。
- 寫入前檢查文件身分、內容是否變動、唯讀狀態與編碼；拒絕寫入時仍保留回覆。
- 內建提示區塊預設鎖定，須明確解鎖才能編輯。
- 錯誤訊息區分傳輸失敗與 HTTP 狀態錯誤。
- 關閉提示區塊視窗時保留工作台使用中的字型。

請使用 x64 Notepad++。本候選版尚未認證最低主程式版本及其他架構；宣告穩定發布前
須完成真實主程式的安裝、升級及移除驗收。日文／西班牙文涵蓋主要工作台，
進階設定部分回退至英文。

替換 DLL 前先關閉 Notepad++，保留舊 DLL 供回復。即使使用可攜版，設定及金鑰仍存於
目前 Windows 使用者的 AppData 與 LocalAppData；移轉測試前應備份且不分享其內容。
雲端服務可能依請求計費。

900 秒不是整個請求的總時間保證；短請求成功也不能證明長時間生成的可靠性。
